# 活动卡片全屏展开编辑 演示（demo）

对应需求 4（2026-11-10 用户反馈）：活动管理画报卡片点击图片/文字等区域无反应或不合预期。
改进方案 demo——**确认通过后再合并进主应用**。

**打开方式**：双击 `index.html`（纯静态零依赖，离线可开；数据为 mock）。

## demo 即提案的新交互（确认后照此合并进 orders.js 活动管理）

1. **「订单」按钮移除**：卡片右上只留「⋯」，卡片视觉保持干净（查订单入口在详情卡内）。
2. **「⋯」= 操作菜单**：查订单 / 打开排谷表 / 导出宣传图 / 购买计划 / 删除活动，
   pop 动画（scale0.95+fade，origin 与触发点同侧）。
3. **左上 IP 名可点击** = 按该 IP 筛选卡片（与左侧 IP 分区栏同语义，再次点击取消）。
4. **点击卡片任意位置（主视图图 / 标题 / 文字区）= 打开全屏详情卡**：
   - 约占屏幕 4/5（86vw × 88vh），内容区滚轮上下滑动；
   - 现活动展开区（actExpandHtml）的能力全部收进详情卡：「商品」tab（商品卡片编辑）+
     「活动信息」tab（名称/IP/状态/日期/链接/主视图等），底部常驻保存与导出操作；
   - 展开动画 = FLIP：面板从原卡片位置缩放平移长大（420ms 减速曲线），
     **主视图图作为共享元素从卡片小图平滑放大移动到详情卡头部大图位**；
     内容头部淡入、列表随后浮入；关闭反向播放（Esc / 右上 × / 点遮罩空白）。
5. `prefers-reduced-motion` 用户直接显隐（无动画）。
