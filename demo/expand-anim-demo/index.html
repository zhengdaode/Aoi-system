展开动画方案对比

一、侧栏分组手风琴（展开/收起）

五个方案同一组件并列，点表头体验；进场用减速曲线（cubic-bezier(0.22,1,0.36,1)）、出场稍快（170ms 加速）。

A1 · 直接显隐（现状对照）无动画

现状 = class 切换瞬间出现/消失。作为对比基线保留。实际观感「生硬」，且用户缺少「内容从哪来」的空间线索。

A2 · max-height 过渡不推荐 · legacy

订单管理 排谷表 国际计算 活动管理

经典写法。缺陷：max-height 必须预设「足够大」的魔法数字——内容比它短时，展开前段在「空转」（视觉延迟感）；内容比它长时会被截断。时长与真实高度不匹配，收起同样失真。仅在需要兼容极旧浏览器时作兜底。

A3 · grid 0fr→1fr推荐基线

订单管理 排谷表 国际计算 活动管理 多加几行也不怕——高度自适应 任意内容长度都精确

外层 grid-template-rows: 0fr → 1fr，内层 overflow:hidden。过渡的是「fr 轨道」，高度自动等于内容真实高度——无魔法数字、时长全程有效，Safari/Firefox/Chrome 全支持。这是 2024 起社区共识的基线做法（CSS-Tricks / Tailwind 均改用此法）。收起时自动换用更快的加速曲线。

A4 · grid + 内容微动最精致 · 建议采用

订单管理 排谷表 国际计算 活动管理

A3 之上叠加：内容淡入 + 下落 5px 归位（延迟 40–60ms 让容器先动），chevron 同曲线旋转。展开时「容器先开、内容随后浮入」，观感最自然；收起时内容先快退、容器再合上。实现仍纯 CSS，成本约 6 行。

A5 · interpolate-size height:autoChromium 129+ 前瞻

订单管理 排谷表 国际计算 活动管理

interpolate-size: allow-keywords（2024 新标准）让 height:0 ↔ height:auto 直接过渡——结构最简、语义最直白。目前仅 Chromium 支持，包在 @supports 里：支持的浏览器有动画，不支持的优雅退化直接显隐。适合作为渐进增强叠加在 A3/A4 之上，不适合作唯一依赖。

二、下拉选择弹层（如「选择批次」下拉）

要点：150–250ms；opacity 搭配 scale ≥0.95（禁止 scale(0)）；transform-origin 锚定触发点同侧；进场减速、出场加速且稍快。

现状。瞬间弹出/消失，无方向感、无层次感。

B2 · scale+fade 弹出推荐 · 标准 pop

opacity + scale(0.95) + translateY(-4px)，transform-origin 顶部左侧（与触发按钮同侧，内容「从按钮处长出来」）。进场 240ms 减速、出场 170ms 加速（时长、曲线由下方调参面板统一控制）。成本极低，观感提升立竿见影——建议全站弹层统一采用。

B3 · 浮现感 + 逐条 stagger进阶可选

B2 之上：弹层带轻微模糊→清晰 + 阴影渐入（「浮现」质感），菜单项逐条错峰入场（每条差 25ms）。列表长时错峰应封顶（如最多前 5 条参与）。观感华丽但动效噪音更多，适合重要弹窗/菜单，不建议所有弹层都用。

调参面板（实时应用到上面 A2–A5 / B2–B3）

依据：M3 标准 200ms；NN/g 弹层 150–250ms；进场减速曲线 cubic-bezier(0.22,1,0.36,1)（ease-out-quint 系），出场加速且略快（170ms）。选一个你观感最舒服的组合，告诉我数值即可照此合并。

:root { --dur-open: 240ms; /* 进场：手风琴/弹层 */ --dur-close: 170ms; /* 出场：略快，干脆收束 */ --ease-open: cubic-bezier(0.22, 1, 0.36, 1); /* 减速曲线（进场） */ --ease-close: cubic-bezier(0.4, 0, 1, 1); /* 加速曲线（出场） */ }

三、落地建议（合并时的取舍）

① 手风琴（侧栏分组、活动管理展开区、设置页折叠卡）→ 方案 A4（grid 0fr→1fr + 内容微动），纯 CSS 全浏览器可用； ② 弹层（批次下拉、右键菜单、操作菜单、弹窗面板）→ 方案 B2 统一 pop（scale0.95+fade，origin 锚定触发点）；重要弹窗可局部用 B3； ③ interpolate-size 作为渐进增强包 @supports 叠加（Chromium 用户获得 height:auto 直通的更简渲染，其他浏览器不受影响）； ④ 时长/曲线全部收敛为 4 个 CSS 变量（--dur-open/--dur-close/--ease-open/--ease-close），一处可调全站生效； ⑤ prefers-reduced-motion: reduce 时动画时长归零（本页已内置演示）——晕动症用户直接显隐； ⑥ 长内容 stagger 封顶（B3 最多前 5 条），避免长列表逐条等待。
