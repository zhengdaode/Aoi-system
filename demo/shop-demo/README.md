# 谷谷商城 · C 端购物演示（F12 demo）

对应计划：[docs/PLAN-F12-CEND-SHOP.md](../../docs/PLAN-F12-CEND-SHOP.md)

**这是什么**：面向买家的淘宝式移动端购物 C 端——**纯静态交互演示**（HTML/CSS/原生 JS，零依赖、零构建、离线可开），数据全部是写死的 mock，登录与支付都不会真实发生。用于评审信息架构与交互形态，**不代表最终实现**。

## 打开方式

直接双击 `index.html`（或任意静态服务器指向本目录）。桌面浏览器会显示为居中手机壳，≤420px 视口即全屏移动端效果。

## 演示路径（建议顺序）

1. **登录**：团员密钥 + CN/QQ 任意输入（页面上注明了正式版的鉴权升级路线）
2. **首页**：搜索「万圣节」「吧唧」「ピカチュウ」试试；点团期卡进入团期详情
3. **团期详情**：团购规则 / 截团倒计时 / 商品网格（点已截团的「初音 17周年」可看截团态）
4. **商品详情**：限购 / 已订进度 / 外币原价 / 购买须知 → 加购或立即购买
5. **购物车**：跨团期分组、数量步进（限购上限）、勾选结算
6. **下单确认**：地址簿选择、金额明细（商品 + 预估国际费 + 国内邮费包邮门槛）、支付渠道
7. **收银台（演示核心）**：唯一尾数金额 + 二维码占位，页面上并列展示了 V1（收款码+账单核销）/ V2（当面付回调）/ V3（收银台跳转）三档方案——模拟支付成功后订单自动核销
8. **订单**：状态 tab / 时间线 / 物流跟踪（预置了一条已发货订单）/ 确认收货 / 取消订单
9. **我的**：个人资料（CN/QQ/手机号脱敏）/ 收货地址簿 / 联系客服（对接工单台说明）

## 数据说明

- 购物车 / 演示订单 / 个人资料 / 登录态存 `localStorage`（键前缀 `sd_`），浏览器控制台执行 `localStorage.clear()` 可重置。
- 商品图为 CSS 渐变 + emoji 占位，正式版将复用管理端商品主档 `activityMeta[].products` 的参考图（转存自有图床通道 v3.9.2 已具备）。
