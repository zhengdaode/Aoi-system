# 桌面侧栏交互方案 演示（demo）

对应需求 1（2026-11-10 用户反馈）：菜单栏（左侧功能列）要求电脑端也保持平时收起，点击头部
「☰（三条杠）」弹出；进一步方案：鼠标移动到左侧边缘也可弹出。两者同时完成。

**打开方式**：双击 `index.html`（纯静态零依赖，离线可开；建议窗口宽度 ≥ 900px）。

## demo 即提案的交互规则（确认后照此合并进主应用）

1. **平时收起**：桌面端侧栏默认不显示，内容区占满整行。
2. **点击弹出（点击模式）**：点头部「☰」弹出后保持打开；再次点 ☰ / 点侧栏内 × / Esc /
   点击内容区空白 / 点击任意导航项完成跳转后自动收起。
3. **左缘悬停弹出（悬停模式）**：鼠标贴到屏幕最左缘（14px 透明热区）即弹出；
   移出侧栏 350ms 后自动收起（防手抖宽限）。悬停打开期间点 ☰ 或点导航项，
   按点击模式语义处理（保持打开 / 正常跳转收起）。
4. **悬浮层（flyout）**：弹出时侧栏浮在内容之上，内容区不移动；可选开启半透明遮罩
   （顶部开关对比观感，默认关）。弹出动画 240ms ease-out-quint（减速）。
5. **手机端不变**：≤767px 维持 v3.31.1 抽屉 + 遮罩（顶部按钮可切窄窗预览）。

## 与现状的差异

- v3.32.1 现状：桌面侧栏「流内折叠」——默认展开、点 ☰ 原位收起/展开（md:hidden 显隐），内容让位。
- 本方案：默认收起 + 弹出式（flyout），符合「平时收起、点 ☰ 弹出」的新要求；内容区恒占满整行。
