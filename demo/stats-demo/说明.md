# 团期复盘统计 · 演示版（F6）说明

> 交给管理层的功能形态审核材料。**页面内全部数据为脚本内置的合成示例**（虚构活动 / 圈名 / 金额），
> 不包含、也不连接任何真实团队数据。

## 怎么打开

双击 `index.html` 即可在浏览器打开。**无需联网、无需安装任何东西**（页面零外部依赖，内网/U盘均可演示）。

## 这个 demo 展示什么

「团期复盘统计」正式版的形态预览，当前包含四个模块：

| 模块 | 内容 | 审核要点 |
|------|------|----------|
| KPI 卡 | 订单总数 / 折合总金额 / 交费回收率 / 进行中活动数 | 指标口径是否符合管理需要，还缺什么指标 |
| 按活动聚合表 | 每个活动的订单数、折合金额、币种、交费回收、进度 | 维度是否够用（是否需要按购买人/月份拆） |
| IP 排行 | 按 IP（作品）聚合的金额条形排行 | 排行是否需要支持切换口径（按订单数/按利润） |
| 交费状态分布 | 已交 / 待审核 / 待交 的笔数分布 | 是否需要下钻到人 |

页顶「选择团期」可切换两个示例团期，展示筛选交互。

## 与正式版的关系

- 这是**独立演示页**，不在 Aoi-system 主系统内；审核通过后按 PLAN-NEXT v3.6.0 排期并入主系统，
  读取真实团队数据、复用主系统的导出（图片/表格）能力。
- 如审核提出修改意见（指标增减、口径调整），直接在本文档上批注或转述即可，demo 页面会先改再并入。

## 技术说明（给开发）

- 单文件静态 HTML + 内联 CSS/JS，无框架、无构建、无外部请求（与主系统「无框架无构建」原则一致）。
- 合成数据集中在脚本顶部 `TERMS` 常量，演示汇率 `RATE_JPY` 亦为合成值。
