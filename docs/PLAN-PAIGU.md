# PLAN-PAIGU — 排谷表（按活动排队表格）

> 状态：**v3.27.0 已实施（2026-10-23）**。与订单管理平行的业务组功能：每个活动一张排谷表，
> 商品按类型分 sheet，位次×买家矩阵，状态色标，插排/撤排/改状态，超排治理，排谷日志，xlsx 导出。

## 一、需求来源与参考图

用户提供了一张谷圈排谷工具的手机截图（「排表详情」页），要求在 Aoi-system 内落地同等能力：
颜色区分买家状态、右键（或自定方式）编辑状态、移动排位先后、增删订单、显示商品图片、
商品按类型分 sheet、可导出、按活动划分入口、适配 PC 与手机、预留 QQ 小程序账号系统的联系方式扩展位。

## 二、术语对照表（参考图 → 本系统）

| 图中术语（谷圈黑话） | 本系统对应 | 说明 |
|---|---|---|
| 排谷表 | **新功能「排谷表」**（`view-paigu`，`js/paigu.js`） | 「谷」= goods；本方案主体 |
| 汇总表（tab） | 汇总表导出（`js/summary-export.js`，v3.7.0 已有） | 每活动采购表+汇总矩阵，本期不重做 |
| 排单表（tab） | 限购计划的「排单数量」（`js/limits.js` `productsForActivity`）+ 发货管理排发表 | 分属两个既有页，本期不含 |
| 删除超排 | **删除超排**：排位数超出限购计划 `limits['type\|model']` 的尾部队列 | 新增超排标记（红框）+ 一键撤排操作 |
| 未交肾 | **未付款**（黄） | 「交肾」=「交钱」谐音；交费审批 `d.payments` 是批次×买家级，排谷表状态是单笔级，两者独立 |
| 已下定 | **已下定**（绿） | 定金粒度，系统原本没有，新增为排谷表状态 |
| 已交肾 | **已付款**（蓝） | 全款；同上 |
| 二次已付 | **已付尾款**（粉） | 系统无分期概念，新增 |
| 已发货 | **已发货**（青） | **不回写**订单 `shipped`——发货流程仍走发货管理（快递单号/合照/团员通知全链路），避免两处状态漂移 |
| 种类（行头） | 商品（制品类型 `type` + 型号 `model`，主档 `activityMeta[].products`） | 图中「种类」行=商品卡（图+名），本表为商品列头 |
| 单价（行） | `price`（人民币价）/ `priceOrig`（外币原价+币种符号） | 主档价优先，缺价回落订单价 |
| 买家头像 | 购买人 `buyer`（圈名）+ 圈名首字圆形占位 | **系统无头像**；后续 QQ 小程序可换 QQ 头像 |
| 点击头像查看用户信息 | 买家信息弹窗：圈名 / `memberMeta[cn].qq` / `addresses[buyer]` / 该活动订单 | 预留小程序联系方式扩展位（`buyerInfo`） |
| 插排 / 撤排 | **插排**：指定位次插入（后续顺延）/ **撤排**：移出队列（订单不动） | 系统原本无排队位次概念，`d.orders` 数组序是唯一隐含顺序 |
| 排谷日志 | **排谷日志**：每活动一份操作留痕（上限 300 条） | 改状态/插排/撤排/调序/加单/删超排都写日志；导出含日志 Sheet |
| 首页/上页/下页/尾页 分页 | **不做分页**：全量滚动渲染 + 位次列吸附（最少 10 行） | 分页会割裂插排/跨页移动操作，与图不同的唯一取舍 |

## 三、已实施设计（v3.27.0）

### 数据模型（零 schema，blob 新键）
```
d.paigu[activity] = {
  updatedAt,
  slots: { 'type|model': [ { id, orderId?, buyer, status, addedAt } ] },
  log:   [ { at, text } ]        // 上限 300，新的在前
}
```
- `status ∈ 未付款 | 已下定 | 已付款 | 已付尾款 | 已发货`；页面 class 与导出填充色一一对应
  （黄 `FEF3C7` / 绿 `BBF7D0` / 蓝 `BFDBFE` / 粉 `FBCFE8` / 青 `A5F3FC`）。
- 排位来源：①勾选已有订单入排（记 `orderId`，**一单只入一个排位**，跨活动防重）；②手动排位
  （无 `orderId`，仅队列虚拟排位，**不建真实订单**——排谷常发生在正式下单前）。
- 悬空订单（订单管理删除后）：排位标 ⚠，菜单提供「转为手动排位」（去 `orderId` 保留买家）或撤排。
- 状态**独立不联动**：不回写订单 `shipped`，不影响交费审批（批次×买家级）。

### 页面与交互
- 入口：业务组导航「排谷表」（订单管理之后）+ 活动管理展开区「排谷表」跳转按钮。
- 活动列表（卡片：状态/排位数/超排数/打开/导出）→ 点活动进表格详情（‹返回）。
- 详情：头部（添加订单 / 排谷日志 / 删除超排[有超排时] / 导出表格）+ 可折叠状态图例 +
  类型 tab（横向滚动）+ 位次×商品矩阵。
- 商品列 = 主档 products ∪ 该活动订单 ∪ 已有排位（主档序优先）；列头两行 = 参考图+型号 / 单价。
- 位次行 = max(10, 最长列排位数)，位次列 sticky 吸附。
- **点排位（电脑可右键 contextmenu）→ 操作菜单**（≤640px 贴底 bottom sheet）：五个状态按钮
  即点即改（当前态 ✓）、上移一位/下移一位、查看买家信息、[悬空时] 转为手动排位、撤排（订单不动）、关闭。
- **点空格 → 插排弹窗**：勾选该列未入排订单和/或手动填买家名 → 插入该位次、后续顺延。
- 表头「添加订单」：该活动全部订单，未排的勾选按商品列追加队尾，已排置灰。
- 超排：`limitPlans[activity].limits` 存在且排位超限 → 超出位次红框 + 图例「超排」+ 一键删除
  （confirm + undo）。
- 弹层纪律沿 v3.25.2 教训：`[data-pact]` document 委托、遮罩捕获阶段关层、容器无 stopPropagation、Esc 关闭。

### 导出
- `Aoi.paigu.buildWorkbook(d, activity)` 纯函数：每类型一个 Sheet（种类/参考图[exceljs 内嵌]/单价/
  位次行带状态色填充）+「排谷日志」Sheet；复用 `Aoi.exportSummary.renderExcelJS/renderPlain` 双通道
  与 `imageCandidates` 图片候选链；文件名 `活动名-排谷表.xlsx`。
