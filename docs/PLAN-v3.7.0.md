## 0. 可行性审核结论（对应用户七项）

1. **图片功能**：合照场景=发货管理批量设合照（`orders[].photo`），此前仅文字链接展示 → S8 升级缩略图；商品图片此前藏在活动商品弹窗不易发现 → S2 展开区使其成为主场景。
2. **活动管理**：购买人收窄为代购人+账号并与计划账号同步（S3）；三处商品统一到 `activityMeta[].products`（S1/S2/S4）；点击活动名行内展开商品卡片区（S2）；UI 流式宽度（S7）。
3. **信息录入预建商品**：改为「登记活动商品」，统一写商品主档；`d.products` 旧池停止读写、数据保留（S4）。
4. **汇总表导出**：复刻 7.8汇总表结构；两处预期偏差=①参考图为链接单元格（WPS DISPIMG 内嵌无法在浏览器端复刻，原文件 24MB 均为图片体积）；②金额按订单逐单 price×count 累计（比手工表更准），单价行为按件加权均价（S5）。
5. **发货 CSV**：删除（bot 排发表 xlsx 私发为另一用途，保留）（S6）。
6. **复盘并入总览**：`#ovStats` 区块，KPI 卡跳转保留，独立导航项移除（S6）。
7. **F9 接口预留**：仅预留不实现——`ensure` 补 `d.pcoItems: []`；商品主档扩展可选 `price/priceOrig/currency/limit` 字段（即 F9「一键推入」目标结构，向后兼容）；关联键沿用 `type+model`（S1）。**版本注：v3.7.0 已被本轮占用，F9 交付版本顺延 v3.8.0。**

## 2. 数据模型变化（blob = team_data.data）

- `activityMeta[活动].products[]`：`{ id, type, model, refImage, refUrl }` → 扩展可选 `price`（人民币登记价）、`priceOrig` + `currency`（外币原价）、`limit`（单账号限购）。**向后兼容**：旧数据三字段缺省，展示层回落订单聚合值。
- 新增 `pcoItems: []`（F9 预留，本期无读写方）。
- `d.products`（旧预建商品池）：**废弃保留**——不再读写与展示，旧数据原样留在 blob 中。
- 购买人同步约定：`activityMeta[活动].buyers[i]`（`{buyer, account, address}`）按行序对应 `limitPlans[活动]` 的账号槽位 `i+1`；保存校验账号必填且圈名/账号唯一。
